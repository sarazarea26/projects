# Amazon Book Sales Analysis Notebook

This notebook analyzes Amazon book sales data to explore trends in pricing, genre popularity, and consumer reading patterns over multiple years.

Key methods:
- Data collection, cleaning, and exploratory analysis using Python
- Visualization of temporal patterns in sales and pricing
- Comparison of genre performance and shifts in reader preferences

Dependencies:
- Python 3
- pandas
- matplotlib
- seaborn

Output:
- The analysis reveals seasonal fluctuations in pricing and sales volume, as well as longer-term changes in genre popularity that align with broader shifts in consumer interest.
